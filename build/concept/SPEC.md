# 개념 4지선다 문항 작성 규격 (帰宅クイズ · 기출 키워드 기반)

입력: /home/claude/kitaku/db/{회차}.json — EJU 종합과목 기출 문항 목록. 각 항목에 id, 과목, 절ID, 절, 무엇을묻는가, 키워드, 발문_ko, 선택지1~4_ko, 정답(1~4), 문제유형, 자료_텍스트 가 있음.

출력: /home/claude/kitaku/concept/{회차}.json — 입력 문항 1개당 **정확히 1개**의 개념 문항. JSON 배열, ensure_ascii=False.
각 원소:
{
  "src": "2024-1-Q07",            // 원 문항 id
  "subj": "정치",                  // 과목 그대로 (정치/경제/현대사회/역사/지리)
  "sec": "POL-003",                // 절ID 그대로 (공란이면 "")
  "q": "…?",                       // 한국어 발문 1문장. 단독으로 성립. 40자 이내 권장
  "c": ["…","…","…","…"],           // 보기 4개, 한국어. 길이 비슷하게
  "a": 1,                          // 정답 index 0~3
  "e": "…",                        // 해설 1~2문장 (왜 정답인지 + 오답 한 줄)
  "kw": ["…","…"]                  // 핵심 키워드 1~3개
}

## 반드시 지킬 것
1. **기출 원문을 베끼지 않는다.** 발문_ko·선택지_ko 문장을 그대로 또는 살짝 바꿔 쓰는 것 금지. 같은 개념을 내 문장으로 새로 낸다.
2. **지문 의존 표현 금지.** "밑줄부 3에 관하여", "앞 페이지의 공란 a", "다음 그래프에서", "지도 중의" 같은 말이 들어가면 안 된다. 문제 하나만 보고 풀 수 있어야 한다.
3. **자료해석·지도판독·계산 문항**은 그 문항이 전제로 하는 개념·지식을 묻는 문항으로 바꾼다. (예: "팔라우 위치를 지도에서 고르시오" → "팔라우가 속하는 지역은?" / 시차 계산 → "시차 계산의 기준이 되는 경도 간격은?" / 통계표 읽기 → 그 표가 보여주는 대표 사실을 묻기)
4. **간단한 개념 확인**이 목적. 한 문항에 개념 하나. 학생이 개념을 모르면 틀리고 알면 맞히는 수준. 나열형("~를 모두 고르면") 금지, "옳지 않은 것은?" 형식은 4문항 중 1개 이하로만.
5. **정답은 반드시 1개**, 오답 3개는 같은 범주 안의 헷갈리는 개념으로. (예: 정답이 "닉슨"이면 오답은 다른 미국 대통령)
6. **일본어 병기 — 읽기 어려운 것만**: 괄호 일본어는 한국 학생이 일본어 시험지에서 알아보기 어려운 경우에만 붙인다 (2026-09-26 결정). 붙이는 것: 한국어와 표현이 다른 말(영국→イギリス, 네덜란드→オランダ, 독일→ドイツ, 미국→アメリカ, 엔저→円安, 고정환율제→固定相場制), 가타카나 인명(フリードマン, ビスマルク), 일본 고유 제도(衆議院, 内閣総理大臣, 国民審査), 米·英·独·仏·ソ 약칭이 든 말(日ソ共同宣言). 붙이지 않는 것: 한국어와 한자가 같은 말(이산화탄소=二酸化炭素, 국회=国会, 간접세=間接税), 발음이 뻔한 가타카나(프랑스=フランス, 유로=ユーロ, 인플레이션=インフレーション), 연도·숫자·일반 단어. 판정 목록: `gloss_keep.json` / `gloss_drop.json`.
7. **조약·기구·협정은 풀네임(약칭)**: 약칭만 쓰거나 「NPT(핵확산방지조약)」처럼 약칭을 앞에 두지 않는다 (2026-09-26 결정). 한 문장 안에서 두 번째부터는 약칭만 써도 된다. 표기: 핵확산방지조약(NPT) · 부분적핵실험금지조약(PTBT) · 포괄적핵실험금지조약(CTBT) · 제1차 전략무기감축조약(START Ⅰ) · 제1차 전략무기제한협정(SALT Ⅰ) · 중거리핵전력폐기조약(INF 전폐조약) · 국제통화기금(IMF) · 국제부흥개발은행(IBRD) · 세계무역기구(WTO) · 관세 및 무역에 관한 일반협정(GATT) · 경제협력개발기구(OECD) · 개발원조위원회(DAC) · 정부개발원조(ODA) · 특별인출권(SDR) · 국제결제은행(BIS) · 북대서양조약기구(NATO) · 동남아시아조약기구(SEATO) · 국제연합(UN) · 유엔개발계획(UNDP) · 국제노동기구(ILO) · 국제형사재판소(ICC) · 연합국 총사령부(GHQ) · 유엔 평화유지활동(PKO) · 유럽연합(EU, 欧州連合) · 유럽공동체(EC, 欧州共同体) · 유럽석탄철강공동체(ECSC) · 유럽자유무역연합(EFTA) · 유럽중앙은행(ECB) · 동남아시아국가연합(ASEAN) · 아세안자유무역지역(AFTA) · 북미자유무역협정(NAFTA) · 미국·멕시코·캐나다 협정(USMCA) · 환태평양경제동반자협정(TPP, 環太平洋パートナーシップ) · 포괄적·점진적 환태평양경제동반자협정(CPTPP) · 석유수출국기구(OPEC) · 아프리카통일기구(OAU) · 경제상호원조회의(COMECON, 코메콘) · 지속가능발전목표(SDGs) · 새천년개발목표(MDGs). 괄호 뒤 조사는 한글 풀네임 끝 글자에 맞춘다(국제통화기금(IMF)이 / 유럽연합(EU)으로). GDP·CO2·G7 같은 지표·수치 약칭은 그대로 둔다.
7. **사실 확인**: 확실한 사실만 쓴다. 확신이 없는 세부 수치·연도는 피하고 더 기본적인 개념을 묻는다. 정답 index(a)와 보기 순서가 맞는지 저장 전에 스스로 재확인한다.
8. 정답 위치(a)는 0~3에 고르게 섞는다.
9. 용어는 일본 EJU 교재식 직역을 우선한다: 수상(首相)/내각총리대신, 중의원·참의원(일본 국회만), 소정당, 저출산고령화, 최고재판소, 국민투표.

## 작업 방식
- python3로 입력 json을 읽어 목록을 확인한 뒤, 회차별로 문항을 작성해 Write 툴로 출력 파일을 저장한다. 한 회차(38문항)씩 저장한다.
- 저장 후 python3로 다시 읽어 (a) 건수 = 입력 건수, (b) 모든 c 길이 4, (c) a가 0~3, (d) q에 "밑줄", "공란", "다음 지도", "그래프", "표 중" 문자열이 없는지 검사하고 위반이 있으면 고친다.
- 마지막 보고에는 회차별 건수와 검사 결과만 쓴다. 문항 본문을 답변에 붙이지 않는다.
